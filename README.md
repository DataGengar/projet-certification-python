# Mon Projet d'Analyse de Données

Ce projet analyse les données de crimes à Los Angeles. Toutes les analyses et modèles portent sur l'année 2024.
L'objectif est de prédire l'ethnie des victimes basé sur les autres variables. 

## Source des Données

Le jeu de données utilisé dans ce projet provient du portail open data officiel de la ville de Los Angeles. Il s'agit du jeu de données "Crime Data from 2020 to Present".

* **Lien direct vers les données :** [Los Angeles Open Data - Crime Data](https://data.lacity.org/Public-Safety/Crime-Data-from-2020-to-Present/2nrs-mtv8)
* **Date d'accès :** Les données ont été téléchargées en avril 2025.

## Installation

1.  Clonez le dépôt :
    `git clone https://github.com/DataGengar/projet-certification-python.git`
2.  Naviguez dans le dossier du projet :
    `cd mon-projet`
3.  Installez les dépendances :
    `pip install -r requirements.txt`

## Utilisation

Pour lancer le script principal d'analyse, exécutez :
`python main.py`
